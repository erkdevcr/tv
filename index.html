Fuentes de video

Una fuente es una carpeta de Google Drive (compartida como "Cualquier persona con el enlace"). La app revisa cada fuente y agrega automáticamente los videos que encuentre a tu videoteca.

Cómo sacarla: Google Cloud Console → crea/usa un proyecto → "APIs y servicios" → habilita Google Drive API → "Credenciales" → "Crear credenciales" → API Key. No necesitas configurar OAuth: con la carpeta compartida como "Cualquiera con el enlace" alcanza.
